# Vibecalci Widgets

A powerful, high-fidelity calculator widget builder with a tactile, hardware-inspired aesthetic.

## Features
- **Widget Palette**: Drag-and-drop components (Numeric, Currency, Sliders, Steppers).
- **Tactile UI**: Neumorphic and mechanical-inspired designs for a premium feel.
- **Live Preview**: Real-time calculations and layout visualization.

## Tech Stack
- React + TypeScript + Vite
- Tailwind CSS
- Lucide React (Icons)
