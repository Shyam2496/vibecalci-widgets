1. Numeric Input Widgets

These are the most common inputs for calculators.

1. Number Input

General numeric entry.

Example:

Loan Amount
[ 250000 ]

Used in:

finance

engineering

science

budgeting

2. Currency Input

Formatted numeric input for money.

Example:

Monthly Income
[ $ 4500 ]

Features:

currency symbol

formatting

large number handling

3. Percentage Input

Used for rates.

Example:

Interest Rate
[ 7.5 % ]

Used in:

finance

tax calculators

growth models

4. Range Slider

Interactive numeric control.

Example:

Age
[ 18 ─────●──── 65 ]

Used in:

simulations

sensitivity analysis

lifestyle calculators

5. Stepper Input (+/−)

Number field with increment buttons.

Example:

Number of people
[-] 4 [+]

Used in:

serving size

quantity calculations

2. Text Input Widgets

Used when numeric input is not enough.

6. Text Field

Single-line text.

Example:

Product Name
[ Laptop ]

Used in:

datasets

labeling

item lists

7. Text Area

Multi-line input.

Example:

Custom formula
[ input text ]

Used in:

formula descriptions

notes

custom datasets

3. Selection Widgets

These allow choosing from predefined options.

8. Dropdown Selector

Example:

Currency
[ USD ▼ ]

Used in:

units

categories

methods

9. Radio Button Group

Example:

Compounding

○ Monthly
○ Quarterly
○ Yearly

Used in:

method selection

calculation modes

10. Checkbox

Example:

☑ Include taxes

Used for optional parameters.

11. Toggle Switch

Example:

Inflation adjustment
[ ON ]

Used for binary choices.

4. Time & Date Widgets

Important for finance and planning tools.

12. Date Picker

Example:

Loan Start Date
[ 01 Jan 2025 ]
13. Time Duration Input

Example:

Loan Term
[ 20 years ]

Often includes units.
